# Examples

- `demo_transcript.txt`: a short **synthetic** interview transcript written only to demonstrate SCAMVERSE.
  It is not a real interview and does not describe real persons or cases. Upload it on the
  *Upload and Analyse* page (default options: speaker labels removed, interviewer turns excluded)
  to reproduce the walkthrough in the paper.
- `benchmark.py`: engine runtime at corpus sizes from 1,000 to 250,000 words (`python examples/benchmark.py`).
